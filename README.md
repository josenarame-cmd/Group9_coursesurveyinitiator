# 🎓 Course Evaluation System

A robust, role-based Java web application built with **Spring MVC** and **MySQL** to manage, distribute, and analyze academic course evaluations.

## ✨ Key Features
* **Role-Based Access Control (RBAC):** Dedicated dashboards and permissions for **Administrators**, **Survey Initiators**, **Teachers**, and **Respondents** (Students/Guests).
* **Dynamic Survey Builder:** Create custom surveys with Single-Choice (Radio), Multiple-Choice (Checkboxes), and Open-Text questions.
* **Real-Time Analytics:** Visual result dashboards for Teachers and Initiators showing calculated percentage progress bars and open-text feedback.
* **Asynchronous Email Notifications:** Automated, non-blocking confirmation emails sent to respondents upon survey completion via secure Google SMTP.
* **Data Integrity & Security:** BCrypt password hashing, duplicate submission prevention, and strict MySQL foreign-key constraints to protect relational data.

## 🛠️ Technologies Used
* **Backend:** Java 11/17+, Spring Framework (MVC, Context, JDBC, Mail), BCrypt
* **Database:** MySQL 8.0+
* **Frontend:** JSP (JavaServer Pages), JSTL, HTML5, CSS3, Vanilla JavaScript
* **Build/Deploy:** Maven, Apache Tomcat 9

## 🚀 Setup & Installation Guide

### Prerequisites
Before you begin, ensure you have the following installed on your machine:
* **Java Development Kit (JDK)** 11 or higher
* **Apache Maven**
* **MySQL Server**
* **Apache Tomcat** (Version 9 recommended)

### Step 1: Database Setup
1. Open your MySQL client (e.g., MySQL Workbench or Command Line).
2. Create a new database named `course_eval_db`.
3. Run the SQL script located at `database/schema.sql` to generate all required tables and relationships.

### Step 2: Google App Password (For Email Functionality)
To allow the application to send confirmation emails, you must generate a secure App Password from a Gmail account:
1. Go to your [Google Account Security Settings](https://myaccount.google.com/security).
2. Ensure **2-Step Verification** is turned ON.
3. Search for **"App Passwords"**.
4. Create a new app (Name it "Course Eval System") and click **Generate**.
5. Copy the **16-letter password** generated by Google (do not include the spaces).

### Step 3: Configure Application Properties
1. Open the project in your IDE and navigate to `src/main/resources/db.properties`.
2. Update the file with your MySQL credentials and your generated Gmail App Password:

```properties
# Database Configuration
db.driver=com.mysql.cj.jdbc.Driver
db.url=jdbc:mysql://localhost:3306/course_eval_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true&generateSimpleParameterMetadata=true
db.username=root
db.password=YOUR_MYSQL_PASSWORD

# Mail Configuration (Gmail SMTP)
mail.host=smtp.gmail.com
mail.port=465
mail.username=YOUR_EMAIL@gmail.com
mail.password=YOUR_16_DIGIT_APP_PASSWORD
```

### Step 4: Build and Deploy
1. Open a terminal in the root directory of the project (where `pom.xml` is located).
2. Clean and build the project using Maven:
   ```bash
   mvn clean package
   ```
3. A `.war` file will be generated inside the `target/` directory.
4. Copy the `.war` file into the `webapps/` folder of your Apache Tomcat installation.
5. Start Tomcat.

### Step 5: First Run
1. Open your web browser and navigate to: `http://localhost:8080/course-eval-system`
2. Click **Register as Admin** on the home page to create your first master account.
3. Log in with your new Admin account to begin adding courses, approving teachers, and managing the system!
